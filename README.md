# Hotel KPI Analyzer

Turn a bookings export from any PMS or channel manager into the three numbers every hotel owner asks for (**Occupancy, ADR and RevPAR**), plus where the revenue actually comes from.

Pure Python, no dependencies. Works on a CSV you can export in two minutes.

## Why

Small and mid-size hotels often have the data but not the report. The PMS dashboard shows today; the owner wants last quarter, by channel, in one place. This tool does that from a plain CSV, so it works with whatever system you use.

## Usage

Requires Python 3.9+.

```bash
git clone https://github.com/snjykhatri34-dot/hotel-kpi-analyzer.git
cd hotel-kpi-analyzer
python -m hotel_kpi data/sample_bookings.csv --rooms 40
```

| Option | Meaning |
|---|---|
| `--rooms N` | Total rooms in the property (required) |
| `--start YYYY-MM-DD` | First night to include. Defaults to the earliest check-in. |
| `--end YYYY-MM-DD` | Last night to include. Defaults to the last occupied night. |
| `--json` | Print the full report as JSON (for spreadsheets, dashboards or other scripts) |

## Input format

One row per booking:

| Column | Example | Notes |
|---|---|---|
| `booking_id` | `B1042` | Any unique ID |
| `room_type` | `Deluxe` | |
| `channel` | `Booking.com` | Where the booking came from |
| `check_in` | `2026-01-14` | ISO date |
| `check_out` | `2026-01-16` | ISO date, after `check_in` |
| `nightly_rate` | `159.00` | Room rate per night, before tax |
| `status` | `confirmed` | `cancelled` rows are excluded from revenue |

## How the numbers are calculated

- **Occupancy** = room nights sold ÷ room nights available (rooms × nights in the period)
- **ADR** (average daily rate) = room revenue ÷ room nights sold
- **RevPAR** (revenue per available room) = room revenue ÷ room nights available
- **Cancellation rate** = cancelled ÷ all bookings arriving in the period

Stays that cross the period boundary are counted only for the nights inside it. Fri and Sat nights are treated as the weekend.

## Sample data

`data/sample_bookings.csv` is fictional, generated by `data/generate_sample.py` for a 40-room property over Q1 2026. Run the script with a different seed to make your own.
